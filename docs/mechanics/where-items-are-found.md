# Where the later items are found

Plan 06 · R28b: the items of the games after Platinum (ids from 1000 in `items.json`, 442 of them) all run since R28 (`docs/mechanics/coverage.md`, "The later games' items"), but none is placed anywhere in Sinnoh: Platinum's own world has only Platinum's items. Plan 40 · GE11 holds every item the rules run (every Mega Stone, Z-Crystal, Drive and Gem, the key items that change a form, every item an evolution asks for and the later mechanics' key items) to a way `ItemSources` finds anywhere in the game or to an owed line naming the plan and session that places it (`ItemSourcesTests.Owed`); its rows below say which. This is where the games themselves give each kind, for the chapters of the later regions to place them (plan 03 · D12 for what Sinnoh may hold of them, plans 19 to 23 for the regions). Hand-written; the games' places are named as their own guides and maps name them, in our own words, and nothing here is read by the game.

A chapter that places an item ticks nothing here: it writes the item into its area's files and the place into this table's last column. `Data/ItemSources.cs` (plan 36 · TR3) is every way the data and the scripts give an item, by region; `TrainingToolsTests.EveryToolCanBeHad` holds the training tools to it and names the plan that owes each tool Sinnoh can't give yet.
