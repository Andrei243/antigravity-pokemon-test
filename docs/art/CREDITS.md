# Credits for third-party assets

Everything else in the game (models, textures, sprites, interface, sounds, text) is generated by the game's own code or made for this project. Nothing is taken from the Pokémon games.

| Asset | Files | Author | License | Source |
|---|---|---|---|---|

The license file ships next to the fonts in every build, as the OFL requires.

## Data

| Data | Files | Author | License | Source |
|---|---|---|---|---|
| Species, move, ability and item data for Generations 5–9; names, categories, egg groups, colours, shapes and hidden abilities for all; the short effect descriptions of moves, abilities and items; the names of species, moves, abilities, items, types, natures, forms and places, and PokeAPI's short prose where it has any, in every language its tables name them in (French, German, Spanish, Italian, Japanese, Korean and Chinese, plan 17 · N3) | `PokemonPlatinumEngine/Data/species.json`, `moves.json`, `abilities.json`, `items.json`, `text/<tag>/names.json` | © Paul Hallett and PokéAPI contributors | BSD 3-Clause (<https://github.com/PokeAPI/pokeapi/blob/master/LICENSE.md>) | PokeAPI CSV files, <https://github.com/PokeAPI/pokeapi> (`data/v2/csv`) |
| Platinum's species, move and item values (Generations 1–4) | the same files | pret contributors | facts read from the decompilation; no text, graphics or sound from it is used | <https://github.com/pret/pokeplatinum> |

`tools/DataImporter` reads both (pinned commits in `tools/DataImporter/Sources.cs`). The Pokédex entries are generated from the data in our own words; the games' Pokédex, move and item texts are not used. Pokémon and Pokémon character names are trademarks of Nintendo.
