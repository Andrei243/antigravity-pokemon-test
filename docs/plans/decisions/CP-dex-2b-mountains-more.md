# Plan 46 · The Carpathian Pokédex, 2b: more of the forests and the mountains (Nos. 87 to 114)

Written 2026-11-12, when the user asked for a Pokédex of about 240 to 250 species. The second file of the mountains' briefs; [the first](CP-dex-1-plateau.md) says how they are read and used. The numbers are given by a script that numbers the whole Pokédex in file order (the `b` files after their area, the Fates, legendaries and mythicals last).

### 87. Mistretel: a boar piglet

- **Evolution**: into Mistretor at level 34.
