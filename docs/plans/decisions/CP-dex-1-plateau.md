# Plan 46 · The Carpathian Pokédex, 1: the starters and the plateau (Nos. 1 to 30)

Written 2026-11-09 at the user's request: a picture brief for every species, so the user can draw them with Gemini before the data sessions (plan 46 · CP3 to CP8). `dotnet run --project tools/GeminiArt -- generate --set carpathia` reads these files; the pictures go to `docs/art/reference/gemini/carpathia/`. **A later stage is sent the picture of the stage it evolves from** (the tool finds it from the earlier stage's Evolution line), so a line is drawn in order: a run of the whole set draws each first stage before the next, and a later stage asked for alone waits until the stage before it has a picture. Redraw an earlier stage and redraw what grows from it after (`--force` with their names). Each entry is a design to approve, change or drop: names in English and Romanian (the user reviews the Romanian, decision 7), the typing, the category and size, the evolution, and the **Look**, which is what Gemini is given. Stats, abilities and moves come with the data batches (CP3), once the pictures are chosen.

The numbers are the Carpathian Pokédex's; the species' own numbers are 10000 + it (plan 46: species from 10001). Every design is our own and must not copy an existing Pokémon.

## The starters
