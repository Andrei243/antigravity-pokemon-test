# Plan 46 · The Carpathian Pokédex, 3b: more of the river, the delta, the sea and the caves (Nos. 147 to 173)

Written 2026-11-12, when the user asked for a Pokédex of about 240 to 250 species. The second file of the river's and caves' briefs; [the first](CP-dex-1-plateau.md) says how they are read and used. The numbers are given by a script that numbers the whole Pokédex in file order (the `b` files after their area, the Fates, legendaries and mythicals last).

### 147. Vidrut: an otter pup
- **Romanian**: Vidruț
- **Typing**: Water
- **The Otter Pup Pokémon**, No. 10147. 0.5 m, 5.0 kg.
