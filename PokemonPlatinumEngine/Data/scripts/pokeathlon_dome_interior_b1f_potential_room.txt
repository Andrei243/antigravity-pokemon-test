# The third of the Pokéathlon Dome's halls under the lobby (plan 20 · J13, the last part; HeartGold's D49R0106). The
# guide stands in the way on to the last hall until it is open (HeartGold's FLAG_UNK_0F1, which hides her), and a guide
# of ours stands aside to the west once it is (the overlay's `npcs`, shown by the same flag).


# The guide before the way on, and the same guide aside
script Guide
  speaker "Guide"
  if flag FLAG_UNK_0F1 goto Open
  say "Beyond me is the last hall. It opens to a Trainer once their team has won three courses."
  end
label Open
  say "Go right ahead! Your wins have opened the last hall."
  end

# What the hall hangs once it is earned (plan 15, the bonuses; HeartGold's Pokégear's and ball's signs): read where each
# would hang, the wall's own words until then. A medal on every one of the five courses for the Pokégear's, silver or
# better on every one for the ball's
script Pokegear
  speaker none
  athlon earned pokegear
  if result == 0 goto Plain
  text "A Pokégear in a frame, its screen showing five medals. The plaque reads: \"For {player}, a medal on every course.\""
  end
label Plain
  sayown
  end

script Ball
  speaker none
  athlon earned ball
  if result == 0 goto Plain
  text "A silver Poké Ball on a stand. The plaque reads: \"For {player}, silver or better on every course.\""
  end
label Plain
  sayown
  end
