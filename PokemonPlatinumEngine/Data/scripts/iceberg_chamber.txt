# The Iceberg Chamber (plan 22 · U10, part b). docs/scripts.md describes the language; the lines are our own, on Black 2's beats (the
# decompilation's res/field/scripts/iceberg_chamber.s, read for the order alone).
#
# Regice stands as a statue at the chamber's head; spoken to, it stirs and is battled at Black 2's level 65. Caught or beaten it is
# gone for good (FLAG_UNOVA_FOUGHT_REGICE); run from, it is back the next time the chamber is come to.
script Regice
  speaker none
  text "The statue of the ice giant began to move!"
  cry "Regice"
  wildbattle "Regice" 65
  if result == 2 goto Fled
  setflag FLAG_UNOVA_FOUGHT_REGICE
  hide self
  text "The chamber is still again..."
  end
label Fled
  hide self
  text "Regice sank away into the depths of the ruins..."
  end


script Plaque
  speaker none
  text "Iceberg Chamber"
  end


script Inscription
  speaker none
  text "Here sleeps the guardian of ice, who keeps watch over these ruins."
  end


script BackToTheDoor
  call UnovaRuinsWayBack
  end
