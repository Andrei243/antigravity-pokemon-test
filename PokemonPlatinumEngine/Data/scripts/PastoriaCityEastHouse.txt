# The Move Relearner's house in Pastoria City (plan 01 · M11, part d), on the original's plan. docs/scripts.md
# describes the language; the lines are our own, on the original's beats (scripts_pastoria_city_east_house.s).
#
# He teaches a Pokémon any move its species learns by level, at or below its own, that it doesn't know, for a Heart
# Scale. That list is plan 12 · Q19's rule (Models/Relearning.cs, which the party menu's REMEMBER asks too), joined
# here by plan 20 · J13, part c's `tutor remember`: the Pokémon is chosen, the move picked from the list, and the
# Heart Scale taken only once the move is learned (a Pokémon that knows four is asked which move is to go).
# Blackthorn City's relearner (blackthorn_move_tutor_house.txt) is the same script.


# PastoriaCityEastHouse_MoveManiac
script Relearner
  say "Everybody calls me the Pokémon Move Maniac. I'd sooner be called a Move Tutor, myself." "I know every move a Pokémon learns as it grows, and I can teach a Pokémon any of them it has let slip."
  if item "Heart Scale" goto Scale
  say "If a Pokémon of yours wants a move back, come and see me with a Heart Scale. That's all I ask."
  end
label Scale
  ask "That's a Heart Scale you have there! Shall I trade it for a move one of your Pokémon has let slip?"
  if no goto Later
  say "Which Pokémon is it to be?"
  choosepokemon
  tutor remember
  if result == 3 goto Egg
  if result == 2 goto Nothing
  if result != 1 goto Later
  tutor learn
  if result == 0 goto GaveUp
  if result == 2 goto Hm
  if result == 3 say "One, two, and... poof! {wearer} forgot {forgotten}. And..."
  take "Heart Scale"
  fanfare levelup
  say "{wearer} remembered {thing}!"
  end
label Later
  say "Come back whenever a Pokémon of yours wants a move back."
  end
label Egg
  say "An Egg hasn't let anything slip yet. It hasn't learned a thing!"
  end
label Nothing
  say "That Pokémon has no move to remember. It knows everything it has learned so far."
  end
label GaveUp
  say "{wearer} did not remember {thing}. Your Heart Scale is safe with you."
  end
label Hm
  say "{forgotten} isn't a move that can be given up like that. {wearer} did not remember {thing}."
  end
