# The S.S. Aqua's captain's room (Johto's leftovers: the captain's granddaughter). docs/scripts.md describes the language; the
# lines are our own, on HeartGold's beat of the voyage, played at the quay as the ship is walked through there.


script OnEnter
  # Where the captain's granddaughter is (Johto's leftovers: VAR_JOHTO_SS_AQUA_GIRL, ours; HeartGold's own flags for
  # her three places): 0 hiding in a cabin, 1 run off below decks, 2 and on back with her grandfather
  setflag FLAG_UNK_217
  setflag FLAG_UNK_218
  setflag FLAG_UNK_219
  if var VAR_JOHTO_SS_AQUA_GIRL == 0 clearflag FLAG_UNK_218
  if var VAR_JOHTO_SS_AQUA_GIRL == 1 clearflag FLAG_UNK_219
  if var VAR_JOHTO_SS_AQUA_GIRL >= 2 clearflag FLAG_UNK_217
  end


# P01R0302_000: the captain, who asks after his granddaughter until she is brought back, and gives a Metal Coat for it
script Captain
  face p01r0302_captain player
  speaker "Captain"
  if var VAR_JOHTO_SS_AQUA_GIRL >= 3 goto Done
  if var VAR_JOHTO_SS_AQUA_GIRL == 2 goto Thanks
  say "Welcome aboard the S.S. Aqua. ...Forgive me, I'm distracted. My granddaughter has slipped away somewhere on the ship again."
  say "She loves to hide. Would you look for her? Try the cabins first."
  end
label Thanks
  say "There she is, safe and sound! Thank you. A captain's thanks isn't much, so please take this as well."
  give "Metal Coat"
  setvar VAR_JOHTO_SS_AQUA_GIRL 3
  end
label Done
  say "Welcome to the bridge! The S.S. Aqua is the fastest ship on these waters. We'll get you where you're going."
  end
