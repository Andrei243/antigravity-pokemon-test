# (Overworld/WarpPanels.cs).

# The beauty guesses the player's favourite Pokémon: the first of the team, as the original's does.


# GlobalTerminal1F_Beauty2
script Favourite
  if var PARTY_COUNT == 0 goto Nobody
  ask "Your favourite is {lead}, isn't it?"
  if no goto Really
  say "There, I was right! I knew it!"
  end
label Really
  say "...Oh? But your favourite really is {lead}, isn't it?"
  end
label Nobody
  say "I want to know what kind of Pokémon everybody likes best."
  end
