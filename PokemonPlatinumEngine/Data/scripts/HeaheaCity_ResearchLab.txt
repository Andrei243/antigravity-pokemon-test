  end


# The Island Scan (plan 23, the rest of the islands; rulings, "The Battle Tree, the power plant, Zygarde's cells and the
# rest of the islands"): Sun and Moon's QR Scanner finds, once a day, a Pokémon of another land on the island chosen, the
# island's own for each day of the week, at its own place. Ours is the laboratory's scanner, used once a day
# (FLAG_DAILY_ALOLA_ISLAND_SCAN; the day's flags are cleared by the game's daily events), in place of Sun and Moon's 100
# points from QR codes; the Pokémon found stands at its place for the rest of the day (FLAG_DAILY_ALOLA_SCAN_<SPECIES>)
# until it has been battled. Sun and Moon's special move each knows and the hour it stays are not kept.
script Scanner
  face self player
  speaker "Scientist"
  if flag FLAG_DAILY_ALOLA_ISLAND_SCAN goto Spent
  say "This machine scans an island for Pokémon that don't usually live in Alola. One scan a day, it's all the power we can spare."
  choose "Which island shall we scan?" "Melemele" "Akala" "Ula'ula" "Poni" "Not now"
  if result == 0 goto Melemele
  if result == 1 goto Akala
  if result == 2 goto Ulaula
  if result == 3 goto Poni
  say "Come back whenever you like. The scanner warms up again every morning."
  end
label Melemele
  if weekday monday goto MelemeleMonday
  if weekday tuesday goto MelemeleTuesday
  if weekday wednesday goto MelemeleWednesday
  if weekday thursday goto MelemeleThursday
  if weekday friday goto MelemeleFriday
  if weekday saturday goto MelemeleSaturday
  if weekday sunday goto MelemeleSunday
  end
label Akala
