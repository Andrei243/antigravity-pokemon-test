# A researcher teaches Metronome to one Pokémon, once in a game, for nothing (Models/MoveTutors.cs, Kanto's table).


script MetronomeTutor
  speaker "Researcher"
  if flag FLAG_TUTOR_METRONOME goto Taught
  ask "I've been studying a move that could do anything at all! Shall I teach Metronome to one of your Pokémon?"
  if no goto Later
  say "Splendid! Which one?"
  choosepokemon
  tutor once "Metronome"
  if result == 1 goto Later
  if result == 2 goto Egg
  if result == 3 goto Cannot
  if result == 4 goto Knows
  tutor learn
  if result == 0 goto Later
  if result == 2 goto Hm
  if result == 3 say "{wearer} forgot {forgotten}. And..."
  fanfare levelup
  say "{wearer} learned {thing}!"
  setflag FLAG_TUTOR_METRONOME
label Taught
  say "Metronome calls up a move at random, any move at all. My research says it's pure chance. Or is it?"
  end
label Later
  say "No? A pity. Science waits for nobody."
  end
label Egg
  say "That's an Egg! I'll teach it when it hatches."
  end
label Cannot
  say "Hmm, that one can't learn it, I'm afraid."
  end
label Knows
  say "That one knows it already!"
  end
label Hm
  say "That move can't be forgotten here. Another time."
  end
