# The Ribbon Syndicate's lift (plan 01 · M11, part c), on the original's plan. docs/scripts.md describes the
# language; the lines are our own, on the original's beats (scripts_resort_area_ribbon_syndicate_elevator.s).
#
# The lift's doors in the back wall of each floor lead into this car, and its attendant asks for the floor. The
# original remembers where its rider came from and aims the car's door there by a command of its own
# (SetSpecialLocation); here the car's door is two ways on one tile, to the ground floor until
# FLAG_RIBBON_SYNDICATE_LIFT_UPSTAIRS (a flag of our own) and to the floor above from it, and the ride sets or
# clears the flag. Each floor says the same as it is come to, so the flag can never be wrong for long.
#
# The ride is the lift's own set piece (plan 09 · L12; the original's PlayElevatorAnimation with its four rounds of
# the car's lights), as the Vista Lighthouse's is: the attendant turns to the door, the indicator's arrow runs the
# way the car goes, the car hums and shudders, and a chime says it has arrived.


script Lift
  choose "Welcome, and thank you for visiting us today. Which floor would you like?" "2F" "1F" "EXIT"
  if result == 0 goto Up
  if result == 2 end
  # ResortAreaRibbonSyndicateElevator_SelectFloor1
  if not flag FLAG_RIBBON_SYNDICATE_LIFT_UPSTAIRS goto Same
  say "Certainly. Going down."
  clearflag FLAG_RIBBON_SYNDICATE_LIFT_UPSTAIRS
  # ResortAreaRibbonSyndicateElevator_ElevatorAnimation
  face self down
  anim elevator down 4
  goto Arrived
# ResortAreaRibbonSyndicateElevator_SelectFloor2
label Up
  if flag FLAG_RIBBON_SYNDICATE_LIFT_UPSTAIRS goto Same
  say "Certainly. Going up."
  setflag FLAG_RIBBON_SYNDICATE_LIFT_UPSTAIRS
  # ResortAreaRibbonSyndicateElevator_ElevatorAnimation
  face self down
  anim elevator up 4
# ResortAreaRibbonSyndicateElevator_HereWeAreMessage
label Arrived
  face self right
  say "Here we are!"
  end
# ResortAreaRibbonSyndicateElevator_SelectCurrentFloor
label Same
  say "Er... But this is that floor already?"
  end
