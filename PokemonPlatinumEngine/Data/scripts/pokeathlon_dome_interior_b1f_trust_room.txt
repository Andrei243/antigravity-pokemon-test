# The second of the Pokéathlon Dome's halls under the lobby (plan 20 · J13, the last part; HeartGold's D49R0105). The
# guide stands in the way on to the hall of potential until it is open (HeartGold's FLAG_UNK_0F0, which hides her), and
# a guide of ours stands aside to the west once it is (the overlay's `npcs`, shown by the same flag).


# The guide before the way on, and the same guide aside
script Guide
  speaker "Guide"
  if flag FLAG_UNK_0F0 goto Open
  say "Beyond me is the hall of potential. It opens to a Trainer once their team has won two courses."
  end
label Open
  say "Go right ahead! Your wins have opened the hall of potential."
  end

# What the hall hangs once it is earned (plan 15, the bonuses; HeartGold's shoes', clothes' and flag's signs, which it
# shows behind flags its own code clears): read where each would hang, the wall's own words until then (`sayown`).
# Earned by the records (AthlonRecords.Has): ten Steady bonuses for the shoes, ten Star bonuses for the clothes, ten
# courses won for the flag
script Shoes
  speaker none
  athlon earned shoes
  if result == 0 goto Plain
  text "A pair of running shoes hangs here, worn thin at the toes. The plaque reads: \"For {player}, who never slipped.\""
  end
label Plain
  sayown
  end

script Clothes
  speaker none
  athlon earned clothes
  if result == 0 goto Plain
  text "A team jersey hangs here, its number stitched in gold. The plaque reads: \"For {player}, whose Pokémon shone.\""
  end
label Plain
  sayown
  end

script Flag
  speaker none
  sayown
  athlon earned flag
  if result == 0 goto Done
  text "Beside them hangs a flag in the dome's sky blue. It reads: \"{player}: ten courses won.\""
label Done
  end
