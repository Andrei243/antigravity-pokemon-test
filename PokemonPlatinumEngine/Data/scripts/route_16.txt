# Route 16 (plan 19 · K5, part b). docs/scripts.md describes the language; the lines are our own, on FireRed's beats
# (data/maps/Route16/scripts.inc).
#
# A Snorlax sleeps across the lane south of the gate. Only the Poké Flute (lavender_town_volunteer_pokemon_house.txt)
# wakes it; woken, it is angry and battles (level 30), and once the battle is over, won, caught or run from, it is
# gone from the road (FLAG_HIDE_ROUTE_16_SNORLAX). Route 12's is the same (route_12.txt).
#
# West of the gate is the head of the Cycling Road (plan 19 · K6): arriving on Route 16 while VAR_MAP_SCENE_ROUTE16
# says the player went onto the road (route_16_north_entrance_1f.txt) puts them on the Bicycle and keeps them there
# until the next door (FireRed's OnTransition and ForcePlayerOntoBike; FLAG_ON_CYCLING_ROAD, which every warp clears).


script OnEnter
  if var VAR_MAP_SCENE_ROUTE16 != 1 end
  bicycle on
  setflag FLAG_ON_CYCLING_ROAD
  end


script Snorlax
  speaker none
  if item "Poké Flute" goto Flute
  text "A sleeping Pokémon blocks the way. It's snoring soundly."
  end
label Flute
  ask "A sleeping Pokémon blocks the way. Use the Poké Flute?"
  if no end
  scene "Snorlax"
  text "{player} played the Poké Flute."
  music "kanto/poke_flute"
  wait 3
  music area
  cry "Snorlax"
  text "Snorlax woke up! It doesn't look happy about it..."
  wildbattle "Snorlax" 30
  setflag FLAG_HIDE_ROUTE_16_SNORLAX
  hide self
  if result == 2 text "Snorlax lumbered off somewhere quieter."
  if result == 1 text "Snorlax calmed down, and lumbered off."
  endscene
  end
