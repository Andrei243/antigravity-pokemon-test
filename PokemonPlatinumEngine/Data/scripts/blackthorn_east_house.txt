# blackthorn_east_house (plan 40 · GE2: the trades of the regions' own people). docs/scripts.md describes the language; the lines are our own,
# on the original's beats. NpcTrades carries each trade's numbers (trades.json, written by tools/DataImporter -- --trades).

script Trade
  speaker "Girl"
  if flag FLAG_TRADED_FOR_DORIS goto Done
  ask "I want a girl Dragonair. Will you swap one for my Dodrio, Doris?"
  if no goto Waiting
  choosepokemon
  if result == 255 goto Waiting
  trade doris
  if result == 0 goto NotWanted
  setflag FLAG_TRADED_FOR_DORIS
  say "A girl Dragonair! Thank you. Doris runs very fast, so mind her."
  end
label NotWanted
  say "That isn't a girl Dragonair. It's a girl Dragonair I want."
  end
label Waiting
  say "Oh. If you find a girl Dragonair, please come back."
  end
label Done
  say "My Dragonair is as graceful as the lake. How is Doris?"
  end
