# own, on the original's beats (scripts_eterna_city_condominiums_1f.s).
#
# A boy trades his Chatot, Charap, for a Buizel (NpcTrades "charap"). FLAG_TRADED_FOR_CHARAP_CHATOT: the trade is
# done.
#
# The Name Rater lives here too (plan 01 · M11, part d: EternaCityCondominiums1F_ExpertM). In the original he gives a
# Pokémon of the player's own a new nickname; the one naming prompt is plan 13 · V4's (plan 12 · Q19 puts RENAME in
# the party menu with it) and isn't written yet, so he judges the name he is shown and changes nothing: a stand-in
# (docs/mechanics/rulings.md).


script Charap
  if flag FLAG_TRADED_FOR_CHARAP_CHATOT goto Done
  ask "Buizel is the coolest Pokémon ever! Will you trade me one for my Chatot?"
  if no goto Waiting
  choosepokemon
  if result == 255 goto Waiting
  trade charap
  if result == 0 goto NotWanted
  setflag FLAG_TRADED_FOR_CHARAP_CHATOT
  say "Yes! A Buizel, all mine! This is the best day ever!"
  end
label NotWanted
  say "That's not a Buizel! I only want a Buizel."
  end
label Waiting
  say "Aww. Come back if you ever find a Buizel, OK?"
  end
label Done
  say "Has Chatot learned Chatter yet? It can say anything you teach it!"
  end


# EternaCityCondominiums1F_ExpertM
script NameRater
  ask "Hello, hello! I am the official Name Rater! Shall I rate the nicknames of your Pokémon?"
  if no goto Again
  say "Whose nickname am I to judge?"
  choosepokemon
  if result == 255 goto Again
  say "{member:RESULT}, is it? Now that is a decent name!" "A better one still? Ah... there you have me. My great book of names is away at the binder's." "Take good care of {member:RESULT} in the meantime!"
  end
label Again
  say "I see. Do come and visit again."
  end
