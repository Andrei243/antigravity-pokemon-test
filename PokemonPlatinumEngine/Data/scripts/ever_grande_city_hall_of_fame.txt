# Hoenn's Hall of Fame (plan 21 · H9). docs/scripts.md describes the language; the lines are our own, on Emerald's beats
# (data/maps/EverGrandeCity_HallOfFame/scripts.inc, and its special GameClear).
#
# One scene, played as the new Champion comes in beside Wallace: his words, the team recorded (halloffame), Hoenn's story
# ended (HoennHallOfFame, the region's flag, which opens the way on, and FLAG_IS_CHAMPION, Emerald's own), the scene of
# the team's entry, the team healed, home to the player's room in Littleroot Town, the game saved there, and the credits.
# The room's floor is Emerald's polished one (MB_ICE, which slides whoever walks on it), so nobody walks here: Wallace
# turns to the player where they stand, where Emerald walks the two up the hall.
#
# What Emerald's EverGrandeCity_HallOfFame_EventScript_SetGameClearFlags sets for the time after, which this game has
# places for: Wally from Victory Road's passage to its way out, the Safari Zone's expansion opened (its builders gone, its
# attendant back), Steven gone travelling from his house in Mossdeep with his Beldum's ball and his letter left on the
# desk (the ball only for a player who hasn't taken it), and the League's rooms, the rival and the professor put back.
# Birch's National Pokédex is his lab's (littleroot_town_professor_birchs_lab.txt).


script OnEnter
  if not flag FLAG_HOENN_DEFEATED_WALLACE end
  scene "Hoenn's Hall of Fame"
  place hall_of_fame_wallace 6 15 right
  face player left
  speaker "Wallace"
  say "This is the Hall of Fame. Here we honour every trainer who has become the Champion of the Pokémon League."
  say "Each of them came here with the Pokémon who stood beside them through every battle. Just as you have."
  face hall_of_fame_wallace up
  face player up
  say "{player}, your name and your Pokémon's will be kept here alongside theirs. Let's record your team."
  endscene
  wait 0.4
  fade out 0.8
  halloffame
  setflag HoennHallOfFame
  objective hoennFree
  setflag FLAG_IS_CHAMPION
  call ClearGame
  call LegendsAgain
  halloffame show
  heal
  warp "LittlerootTown_BrendansHouse_2F" 4 2 down
  save
  if result == 0 goto NotSaved
  sound "save"
  text "{player} saved the game."
  goto Roll
label NotSaved
  text "The game could not be saved."
label Roll
  credits
  end


# What a victory leaves behind for the time after (Emerald's SetGameClearFlags, the parts this game has places for)
script ClearGame
  setflag FLAG_HIDE_VICTORY_ROAD_ENTRANCE_WALLY
  clearflag FLAG_HIDE_VICTORY_ROAD_EXIT_WALLY
  setflag FLAG_HIDE_SAFARI_ZONE_SOUTH_CONSTRUCTION_WORKERS
  clearflag FLAG_HIDE_SAFARI_ZONE_SOUTH_EAST_EXPANSION
  setflag FLAG_HIDE_MOSSDEEP_CITY_STEVENS_HOUSE_STEVEN
  clearflag FLAG_HIDE_MOSSDEEP_CITY_STEVENS_HOUSE_INVISIBLE_NINJA_BOY
  if not flag FLAG_RECEIVED_BELDUM clearflag FLAG_HIDE_MOSSDEEP_CITY_STEVENS_HOUSE_BELDUM_POKEBALL
  setflag FLAG_HIDE_CHAMPIONS_ROOM_RIVAL
  setflag FLAG_HIDE_CHAMPIONS_ROOM_BIRCH
  clearflag FLAG_DEFEATED_ELITE_4_SIDNEY
  clearflag FLAG_DEFEATED_ELITE_4_PHOEBE
  clearflag FLAG_DEFEATED_ELITE_4_GLACIA
  clearflag FLAG_DEFEATED_ELITE_4_DRAKE
  clearflag FLAG_HOENN_DEFEATED_WALLACE
  return


# Hoenn's legendaries met again (plan 40 · GE6): each one beaten and not caught is back in its place once the Hall of
# Fame is entered again (its place's arrival shows it while its beaten flag is clear; Kyogre's and Groudon's caves open
# again with the Weather Institute's next report), Jirachi wakes again the next night Steven is spoken to, Deoxys's stone
# is back on Birth Island, and the eon roamer, knocked out, is set loose again. Steven's friend's pair in Pewter City is
# a meeting once only
script LegendsAgain
  if not flag FLAG_HOENN_CAUGHT_REGIROCK clearflag FLAG_DEFEATED_REGIROCK
  if not flag FLAG_HOENN_CAUGHT_REGICE clearflag FLAG_DEFEATED_REGICE
  if not flag FLAG_HOENN_CAUGHT_REGISTEEL clearflag FLAG_DEFEATED_REGISTEEL
  if not flag FLAG_HOENN_CAUGHT_RAYQUAZA clearflag FLAG_DEFEATED_RAYQUAZA
  if not flag FLAG_HOENN_CAUGHT_KYOGRE clearflag FLAG_DEFEATED_KYOGRE
  if not flag FLAG_HOENN_CAUGHT_GROUDON clearflag FLAG_DEFEATED_GROUDON
  if not flag FLAG_HOENN_CAUGHT_JIRACHI clearflag FLAG_HOENN_JIRACHI_MET
  if not flag FLAG_CAUGHT_HO_OH clearflag FLAG_DEFEATED_HO_OH
  if not flag FLAG_CAUGHT_LUGIA clearflag FLAG_DEFEATED_LUGIA
  if not flag FLAG_CAUGHT_MEW clearflag FLAG_DEFEATED_MEW
  clearflag FLAG_DEFEATED_DEOXYS
  if not flag FLAG_CAUGHT_LATIAS_OR_LATIOS clearflag FLAG_DEFEATED_LATIAS_OR_LATIOS
  if var VAR_ROAMING_LATIAS_STATE == 2 roamer start "Latias"
  if var VAR_ROAMING_LATIAS_STATE == 2 setvar VAR_ROAMING_LATIAS_STATE 0
  if var VAR_ROAMING_LATIOS_STATE == 2 roamer start "Latios"
  if var VAR_ROAMING_LATIOS_STATE == 2 setvar VAR_ROAMING_LATIOS_STATE 0
  return
