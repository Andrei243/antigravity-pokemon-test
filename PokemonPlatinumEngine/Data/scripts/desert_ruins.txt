# The Desert Ruins (plan 21 · H12, part a). docs/scripts.md describes the language; the lines are our own, on Emerald's
# beats (data/maps/DesertRuins/scripts.inc).
#
# A wall of dots shuts the chamber where Regirock waits. Standing before it at 8, 21 (the overlay's braille spot) and using
# Rock Smash breaks it, once the Sealed Chamber's doors have been opened (FLAG_REGI_DOORS_OPENED): the slabs go and the way
# through opens (FLAG_SYS_REGIROCK_PUZZLE_COMPLETED). Regirock is shown by the arrival while it has not been beaten or
# caught (FLAG_DEFEATED_REGIROCK), and is battled at level 40 as Emerald's StartRegiBattle does. Run from, it is back
# with the next arrival; beaten or caught, gone for good.


script OnEnter
  if not flag FLAG_HOENN_CHAPTER_FOURTEEN call HoennChapterFourteen
  if flag FLAG_DEFEATED_REGIROCK end
  clearflag FLAG_HIDE_REGIROCK
  end


# The wall's dots (and the slabs before them), before and after the way through is open
script Wall
  speaker none
  if flag FLAG_SYS_REGIROCK_PUZZLE_COMPLETED goto Open
  text "Rows of raised dots cover the wall. They seem to say: use Rock Smash."
  end
label Open
  text "There is a big hole in the wall."
  end


# Rock Smash used before the wall
script RockSmashThrough
  if flag FLAG_SYS_REGIROCK_PUZZLE_COMPLETED goto Done
  if not flag FLAG_REGI_DOORS_OPENED goto Nothing
  usemove "Rock Smash"
  sound "rock_smash"
  camera shake 1
  wait 0.8
  speaker none
  text "The wall crumbled away, and a way into the dark chamber opened up!"
  setflag FLAG_SYS_REGIROCK_PUZZLE_COMPLETED
  end
label Nothing
  usemove "Rock Smash"
  speaker none
  text "But nothing happened..."
  end
label Done
  speaker none
  text "The wall has been broken already."
  end


script Regirock
  cry "Regirock"
  speaker none
  text "Regirock stands in the dark, as still as a stone."
  wildbattle "Regirock" 40
  hide self
  setflag FLAG_HIDE_REGIROCK
  if result == 2 goto Fled
  setflag FLAG_DEFEATED_REGIROCK
  end
label Fled
  text "Regirock vanished into the dark of the ruins..."
  end
